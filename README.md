# 가전 고르는 기준

제품군별로 "사기 전에 무엇을 확인해야 하는가"를 정리하는 사이트.

- `keywords.mjs` — 네이버 자동완성에서 실제 검색어를 모은다 (무료·키 불필요)
- `specs.mjs` — 제품군별 선택 기준. **제품명·가격·스펙은 넣지 않는다**
- `post.mjs` — 본문 조립. FAQ는 실제 검색어에서만 뽑는다
- `build.mjs` — 정적 HTML + 사이트맵 + robots

## 원칙

확인하지 못한 값은 쓰지 않는다. 가격과 성능 수치는 시기·유통에 따라 달라져
글에 박으면 곧 거짓이 된다. 대신 **무엇을 기준으로 고르는가**를 쓴다.
