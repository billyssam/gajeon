# 블로그&구글 이미지 권리 대장 — 2026-09-16

## 판정

- 대상: 승인 대기 원고 5편, 카드 16장
- 출처 유형: 프로젝트 내부 카드 생성기에서 만든 개념 일러스트(SVG 기반 렌더링)
- 외부 사진·브랜드 로고·타인 초상·상품 상세페이지 캡처: 사용하지 않음
- 카드 시각 검수: 16/16 확인
- 대체텍스트·본문 고지: 원고 QA에서 확인
- 발행 전 재확인: 상품 선정 시점에 실제 외부 이미지가 추가되면 별도 권리 증적 없이는 삽입하지 않음

## 운영 규칙

1. 승인 전에는 제휴·광고 이미지를 삽입하지 않는다.
2. 외부 이미지를 쓰게 되면 URL, 제공자, 라이선스, 확인일을 이 대장에 먼저 기록한다.
3. 권리 증적이 없는 이미지는 자동으로 발행 보류한다.
